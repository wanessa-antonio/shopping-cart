# 🛍️ Carrinho de Compras - React

Aplicação de e-commerce desenvolvida com React, permitindo que usuários adicionem produtos ao carrinho e visualizem o valor total da compra.

🔗 **Acesse o projeto online:**  
https://carrinho-de-compra.netlify.app

---

## 📌 Sobre o projeto

Este projeto simula um sistema de carrinho de compras, onde os produtos são carregados dinamicamente através de uma API externa.

Os usuários podem:

- Visualizar produtos disponíveis
- Adicionar itens ao carrinho
- Remover itens do carrinho
- Visualizar o valor total da compra
- Manter os itens salvos mesmo após atualizar a página (LocalStorage)

---

## 🚀 Tecnologias utilizadas

- React
- JavaScript (ES6+)
- HTML5
- CSS3
- LocalStorage
- API pública

---

## 🔗 API utilizada

Os dados dos produtos (imagens, títulos, descrições e preços) são consumidos da API:

https://fakestoreapi.com/products

---

## 🎯 Funcionalidades

- Consumo de API com React
- Renderização dinâmica de produtos
- Sistema de carrinho de compras
- Cálculo automático do valor total
- Persistência de dados com LocalStorage
- Interface organizada e responsiva

---

## 💡 Objetivo do projeto

Este projeto foi desenvolvido para:

- Praticar consumo de API com React
- Trabalhar com gerenciamento de estado
- Implementar lógica de carrinho de compras
- Utilizar LocalStorage para persistência de dados
- Melhorar habilidades em desenvolvimento front-end
